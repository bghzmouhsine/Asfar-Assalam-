# Café Mouhsine BOUAGHAZ ☕

منصة رقمية احترافية لمقهى **Café Mouhsine BOUAGHAZ** — موقع ثابت (HTML/CSS/JS) بدون أي خادم، جاهز للنشر على GitHub Pages أو Netlify أو أي استضافة.

## المميزات
- **قائمة رقمية** بـ 35 منتوجاً مع الصور والأسعار بالدرهم، مقسمة إلى 8 فئات، مع بحث وترتيب حسب السعر، وعرض "لائحة أسعار" قابلة للطباعة.
- **أحجام وأسعار متعددة** (M/L، كأس/براد، 250غ/500غ/1كغ…) ووسوم: الأكثر طلباً، جديد، مغربي أصيل، توقيع البيت.
- **سلة طلبات**: على الطاولة / سفري / توصيل، رسوم التوصيل (مجاني فوق 150 درهم)، أكواد الخصم (`MOUHSINE10`، `BIENVENUE`، `COFFEE20`)، والإرسال عبر **واتساب**.
- **خدمات بأسعار واضحة**: التوصيل، فضاء العمل، كراء القاعة، الكوفي بريك، ورشة الباريستا، اشتراك البن الشهري.
- **حجز طاولات وخدمات** مع التحقق من أوقات العمل وتأكيد عبر واتساب.
- **بطاقة ولاء رقمية** (Bronze / Silver / Gold) تُحتسب نقاطها تلقائياً مع كل طلب.
- **قائمة QR** قابلة للتحميل والطباعة على الطاولات.
- **3 لغات**: العربية (RTL)، الفرنسية، الإنجليزية — و**وضع ليلي/نهاري** بألوان القهوة.
- **حالة "مفتوح الآن"** مباشرة، أوقات العمل، الخريطة، معرض الصور وآراء الزبناء.
- **تطبيق ويب (PWA)**: قابل للتثبيت على الهاتف ويعمل بدون إنترنت.
- **لوحة الإدارة** `admin.html` (الرمز الافتراضي `1234`): إحصائيات الطلبات، الأكثر مبيعاً، الحجوزات، تعديل الأسعار والتوفر، تصدير/استيراد JSON.

## التخصيص
كل البيانات في `js/data.js`:
- `CAFE_CONFIG`: رقم واتساب، البريد، العنوان، أوقات العمل، رسوم التوصيل.
- `CAFE_PRODUCTS`: المنتوجات والأسعار والصور.
- `CAFE_SERVICES`: الخدمات وأسعارها.

> ⚠️ رقم الهاتف `+212600000000` والعنوان وصور Unsplash هي قيم مؤقتة — استبدلها بمعلومات وصور المقهى الحقيقية.
> لوحة الإدارة تحفظ التعديلات في المتصفح فقط؛ لتعميمها على جميع الزبناء حدّث `js/data.js`. رمز الدخول حماية واجهة بسيطة وليس نظام أمان.

## التشغيل محلياً
```bash
cd cafe-mouhsine
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
