# Café Mouhsine BOUAGHAZ ☕

منصة رقمية احترافية لمقهى **Café Mouhsine BOUAGHAZ** — موقع ثابت (HTML/CSS/JS) بدون أي خادم، جاهز للنشر على GitHub Pages أو Netlify أو أي استضافة.

## المميزات
- **قائمة رقمية** بـ 40 منتوجاً (منها 5 عروض) مع الصور والأسعار بالدرهم، مقسمة إلى 8 فئات، مع بحث وترتيب حسب السعر، وعرض "لائحة أسعار" قابلة للطباعة.
- **أحجام وأسعار متعددة** (M/L، كأس/براد، 250غ/500غ/1كغ…) ووسوم: الأكثر طلباً، جديد، مغربي أصيل، توقيع البيت.
- **تخصيص المشروبات**: نوع الحليب (عادي، بدون لاكتوز، شوفان، لوز)، جرعة إسبريسو إضافية، كريمة، نكهات (فانيليا، كراميل، بندق) ومستوى السكر — مع احتساب السعر تلقائياً.
- **عروض وفورمولات**: فطور سريع، عرض الطالب، الثنائي، برانش بلدي، علبة المكتب — مع إظهار قيمة التوفير.
- **ساعة السعادة التلقائية**: خصم 20٪ على المشروبات الباردة والعصائر من الإثنين إلى الجمعة 15:00–17:00 (قابل للتعديل في `CAFE_CONFIG.happyHour`).
- **فلتر النظام الغذائي** (نباتي، نباتي صرف، بدون غلوتين) و**مسببات الحساسية** لكل منتوج.
- **طلباتي السابقة** مع زر "إعادة الطلب" بنقرة واحدة.
- **سلة طلبات**: على الطاولة / سفري / توصيل، رسوم التوصيل (مجاني فوق 150 درهم)، أكواد الخصم (`MOUHSINE10`، `BIENVENUE`، `COFFEE20`)، والإرسال عبر **واتساب**.
- **خدمات بأسعار واضحة**: التوصيل، فضاء العمل، كراء القاعة، الكوفي بريك، ورشة الباريستا، اشتراك البن الشهري.
- **حجز طاولات وخدمات** مع التحقق من أوقات العمل وتأكيد عبر واتساب.
- **بطاقة ولاء رقمية** (Bronze / Silver / Gold) تُحتسب نقاطها تلقائياً مع كل طلب.
- **قائمة QR** قابلة للتحميل والطباعة على الطاولات.
- **صفحة الطباعة** `menu-print.html`: قائمة أسعار A4 بثلاث لغات + **بطاقات طاولات QR** مرقمة؛ مسح بطاقة الطاولة يفتح القائمة ويملأ رقم الطاولة تلقائياً (`?table=7`).
- **3 لغات**: العربية (RTL)، الفرنسية، الإنجليزية — و**وضع ليلي/نهاري** بألوان القهوة.
- **حالة "مفتوح الآن"** مباشرة، أوقات العمل، الخريطة، معرض الصور وآراء الزبناء.
- **تطبيق ويب (PWA)**: قابل للتثبيت على الهاتف ويعمل بدون إنترنت.
- **شاشة المطبخ** `kitchen.html` (نفس رمز الإدارة): أعمدة جديدة / قيد التحضير / جاهزة، مؤقت لكل طلب (برتقالي بعد 8 دقائق، أحمر بعد 15)، تصفية حسب البار أو المطبخ، تنبيه صوتي، شطب كل منتوج عند تحضيره، إضافة طلبات الكونتوار وواتساب يدوياً، والعربية/الفرنسية. حالة الطلب تظهر للزبون في "طلباتي السابقة".
  > بدون خادم، الشاشة ترى الطلبات المسجلة على نفس الجهاز (مثلاً لوحة الكونتوار). لاستقبال طلبات هواتف الزبناء مباشرة يجب ربط المنصة بقاعدة بيانات مشتركة.
- **لوحة الإدارة** `admin.html` (الرمز الافتراضي `1234`): إحصائيات الطلبات، الأكثر مبيعاً، الحجوزات، تعديل الأسعار والتوفر، تصدير/استيراد JSON.

## التخصيص
كل البيانات في `js/data.js`:
- `CAFE_CONFIG`: رقم واتساب، البريد، العنوان، أوقات العمل، رسوم التوصيل.
- `CAFE_PRODUCTS`: المنتوجات والأسعار والصور.
- `CAFE_SERVICES`: الخدمات وأسعارها.
- `CAFE_EXTRAS`: خيارات تخصيص المشروبات وأسعارها.
- في آخر الملف: الخيارات المتاحة لكل منتوج، النظام الغذائي ومسببات الحساسية.

> ⚠️ رقم الهاتف `+212600000000` والعنوان وصور Unsplash هي قيم مؤقتة — استبدلها بمعلومات وصور المقهى الحقيقية.
> لوحة الإدارة تحفظ التعديلات في المتصفح فقط؛ لتعميمها على جميع الزبناء حدّث `js/data.js`. رمز الدخول حماية واجهة بسيطة وليس نظام أمان.

## التشغيل محلياً
```bash
cd cafe-mouhsine
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
